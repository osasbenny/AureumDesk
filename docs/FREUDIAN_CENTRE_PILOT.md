# The Freudian Centre Pilot

## Objective
Demonstrate a working AureumDesk healthcare front office to The Freudian Centre.

## Prototype channels
Phone/IVR and WhatsApp text/voice-note workflows.

## Initial journeys
1. General enquiry -> approved knowledge -> answer or human handoff.
2. Appointment request -> availability -> confirmation -> booking.
3. Prescription refill -> request intake -> authorized human review.
4. Department request -> routing -> staff handoff.
5. Explicit human request -> immediate handoff/fallback.

## Demonstration principle
The prototype should be a working artifact, not merely a proposal. Use synthetic/test data until the Centre approves production integration and data handling.

## Customer-specific values to obtain
Phone/PBX details, WhatsApp account, appointment system, departments, staff routing, hours, approved knowledge, refill rules, escalation policy and production security/privacy requirements.
