# AureumDesk Requirements

## Product
AureumDesk — Aureum AI Front Office

## First deployment
The Freudian Centre, Lagos, Nigeria

## MVP channels
Phone/IVR integration boundary, WhatsApp text, WhatsApp voice notes.

## MVP capabilities
General information; appointment availability/booking; prescription refill request intake with human review; department routing; human handoff; conversation state; knowledge base; organization configuration; audit events; tests; AWS deployment path.

## Safety
No autonomous diagnosis, prescribing, medication changes, dispensing authorization or clinical decisions.

## Reusability
Healthcare is the first vertical. The same core must support future Real Estate, Hospitality, Banking, Insurance, Education, Logistics, Fundraising and other deployments.

## External inputs
Phone/carrier routing, WhatsApp credentials, scheduling API, staff destinations, approved organization knowledge, privacy/security requirements, production AWS configuration and other customer-specific values must be obtained rather than invented.
