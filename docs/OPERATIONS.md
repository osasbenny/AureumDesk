# AureumDesk Operations

## Monitor
Webhook delivery, message processing, AI latency, tool failures, handoffs, appointment actions, refill requests, voice sessions, queue depth and provider errors.

## Incident principles
Protect customer/patient data; disable a failing integration safely; preserve audit events; fall back to human support where configured; never fabricate success.

## Maintenance
Review knowledge, prompts/policies, provider usage, logs, errors and handoff rates regularly. Keep organization-specific configuration separate from reusable product code.
